# Сервис спортивного резюме

Человек заполняет анкету — получает лист, который можно отправить в клуб ссылкой
или сохранить в PDF. По желанию просится в раздел «Люди футбола», куда попадает
только после проверки Александром.

## Где живёт и почему именно там

**На российском сервере, рядом с CRM. Не на Railway и никогда туда не уедет.**

В анкете персональные данные: ФИО, дата рождения, гражданство, фотография,
телефон, почта, места работы, файлы портфолио. По 152-ФЗ (ст. 18 ч. 5) первичная
база персданных россиян обязана находиться в России. Сайт futbologik.ru стоит
на Railway в США — значит сервис резюме там жить не может. На сайте только ссылка.

## Установка

```bash
sudo bash установка.sh rezume.futbologik.ru
```

Перед этим — А-запись `rezume` на IP сервера в Cloudflare, **обязательно DNS only,
серое облако**. Через прокси не пойдёт certbot, и, что важнее, персданные не должны
транзитом идти через чужие серверы.

Повторный запуск обновляет код и перезапускает службу — данные не трогает.

## Из чего состоит

| Файл | Что делает |
|---|---|
| `app.py` | сервер, маршруты, разбор multipart, модерация |
| `core.py` | база, файлы, транслитерация, возраст |
| `view.py` | отрисовка листа резюме |
| `form.py` | анкета с живым предпросмотром |
| `style.py` | стили, включая печать на A4 |

Ни одной внешней зависимости — только стандартная библиотека Python 3.
Тот же приём, что в CRM: обновление это `git pull` и перезапуск службы.

## Как устроен доступ

- **Анкета** — по секретной ссылке `/e/<токен>`. Ни пароля, ни регистрации:
  ссылку человек хранит сам. Потерял — заводит заново.
- **Лист** — `/r/<имя>`. Пока не опубликован, открывается только с токеном.
- **Модерация** — `/admin`, пароль выдаётся при установке и лежит
  в `/var/lib/ftbl-rezume/.pass`.

Вход через Telegram добавляется поверх этой схемы и её не ломает.

## Согласия

Две галочки, и они разные:

1. **Обработка персданных** — обязательная, без неё анкета не сохраняется.
2. **Публикация в «Людях футбола»** — отдельная. Человек может хотеть резюме
   и не хотеть публичности.

Телефон и почта не публикуются никогда, даже в опубликованном профиле.

## Правила по текстам

Слово «курс» на страницах сервиса запрещено — правовой протокол после дела
по ЗоЗПП. В анкете блок называется «Программы и треки». В образце резюме,
с которого списывали структуру, он назывался «Дополнительное образование/курсы» —
у себя так писать нельзя.

## Что делает ежедневная копия

`/etc/cron.daily/ftbl-rezume-backup` кладёт в `/var/lib/ftbl-rezume/backup`
снимок базы и архив загруженных файлов, хранит 14 дней.
